# 公開・提出の範囲

公開対象は現行コード、設定、world、固定済みモデル、学習・校正データ、必要な回帰テスト、代表結果と起動手順。
講義資料、Dockerイメージ本体、`.env`、APIキー、仮想環境、大量の生ログ、キャッシュは含めない。

この公開リポジトリは、提出版のファイルから新しい履歴を開始した。
試作や旧モデルを含む開発用Git履歴は、リポジトリ外の手元バックアップで保管し、公開対象に含めない。
現在のresultsに残した過去のソースパス・ハッシュは実験当時の出典であり、現在の入口から実行する依存ではない。
古い全実験を現在の入口で再実行できる、という説明はしない。

PDFレポートとMP4動画は別の提出物。PDFは課題の指定先へ、動画は本人のYouTubeアカウントへアップロードしURLを提出する。
このリポジトリはコード提出用としてpublicにする。
代表例だけで全未知荷物の安全や最適性を主張しない。
